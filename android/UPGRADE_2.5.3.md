# Flux 2.5.3 — Compact Library and settled notifications

Library now uses a small header, one All/Video/Audio/Photos row and one Newest/Options toolbar. Search expands only when requested. Status, Favourites only, List/Grid layout, Compact/Small/Medium/Large sizing and Collections & file tools live in the Options sheet. Media rows get more space and compact rows have smaller gaps. Existing layout, size and sort preferences and backup format remain compatible. Compact is a dense list mode; selecting another size returns it to List. Grid retains its own size choice.

The Options button counts active search, media-type, favourite, status and collection filters. Clear filters restores an unfiltered view while preserving layout/size/sort, selection, files and history. Result counts reflect the filtered view. Select downloads remains available through the header icon.

Only actively downloading, merging or saving items use Android's animated download icon and progress bar. Completed items use a static checkmark, paused items a static pause icon, failed items a static error icon and waiting/retrying items a static clock. Stopped states explicitly remove progress and ongoing flags. Late updates from an earlier state are rejected. Cancelling removes the item's notification. Reopening Flux repairs notifications from older versions when their stored item has already stopped/completed. Queue/export service indicators use static icons and end when their workers exit.

Completed notifications offer Share using a temporary read-only grant for the saved content URI. Open is shown when Android reports a compatible viewer. Both actions use immutable PendingIntents; notification taps still open Flux. No new dependency, permission, retrieval service or background player is added. Threads support and prior editing/downloading/settings behavior remain available. Source restrictions and phone-specific notification styling still apply.

Validation includes native pause/resume/download completion notifications, all stopped-state icon/progress flags, repair of legacy animated completion notices, actual release Options controls and filter resets, saved layout/size changes, selection and history/file integrity checks. GitHub device checks use Android 30 x86_64; physical OEM notification behavior remains unverified. A generated design mockup is a proposal, not a release screenshot.
